# Part 3 — Test Cases

The Excel workbook contains exactly 10 formal functional test cases. Coverage includes:

- one positive end-to-end product-to-cart scenario;
- multiple negative scenarios;
- boundary/edge scenarios for quantity, stock and dependent options;
- database validation guidance in all 10 cases.

Negative and boundary coverage is included inside the 10-case total to stay within the assignment's requested 6–12 test-case range.
